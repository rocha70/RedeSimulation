Simulador de Rede Cisco
Arraste os equipamentos. Toque em um equipamento para abrir o terminal. Use ? para ver os comandos do modo atual.
Exemplo de configuração de roteador
enable
configure terminal
hostname R1
interface g0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
end
show ip interface brief
PC: ip 192.168.1.10 255.255.255.0 192.168.1.1 e depois ping 192.168.1.1. Switch: VLANs com vlan 10 e switchport access vlan 10.
